# Solstice: Golden Hour

A browser-based tactical shooter, currently in **beta**.

Current version: **1.0**. Download the Windows build from the [Releases](../../releases) page.

- **Solo:** open `index.html` in a modern browser.
- **LAN (1.5+):** run `Start-LAN.bat` from the release folder (it uses the bundled `Solstice-LAN.exe`, no Python needed). Guests open the join address shown in a browser.
